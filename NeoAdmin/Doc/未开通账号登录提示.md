# 未开通账号登录提示

> 说明如何配置「注册后待审核 / 账号未开通」用户在登录页看到的提示文案。  
> 相关代码：`NeoAdmin.Blazor/Core/Identity/NeoAdminAuthService.cs`、`Components/Auth/DefaultLogin.razor`。

---

## 适用场景

- 用户注册后需管理员审核，审核通过前不能进入后台
- 账号被管理员禁用，登录时需要给出明确业务提示（而非笼统的「用户名或密码错误」）
- 不同禁用原因需要不同提示（例如「审核中」「已拒绝」「已离职」）

框架**没有单独的「审核状态」字段**，统一用 `SysUser.IsEnabled` 表示账号是否已开通。

| `IsEnabled` | 含义 |
|-------------|------|
| `true`（默认） | 账号已开通，可正常登录 |
| `false` | 账号未开通或已禁用，登录会被拒绝 |

---

## 工作原理

```
用户提交登录（DefaultLogin.razor）
        │
        ▼
NeoAdminAuthService.LoginAsync
        │
        ├─ 用户名/密码错误 → 返回「用户名或密码错误…」
        │
        ├─ IsEnabled == false
        │       │
        │       ├─ 已注册 IDisabledAccountLoginMessageResolver → 使用宿主自定义文案
        │       └─ 未注册或返回空 → 默认「账户已被禁用」
        │
        └─ IsEnabled == true → 签发 Token，登录成功
```

登录页只负责展示后端返回的 `Message`，不内置「审核」相关文案：

```csharp
// DefaultLogin.razor — HandleLoginAsync
ToastService.Error("登录失败", result.Message ?? "用户名或密码错误");
```

Toast 标题固定为 **「登录失败」**，正文来自 `NeoAdminAuthService` 返回的 `result.Message`。

---

## 默认行为

未在 DI 中注册 `IDisabledAccountLoginMessageResolver` 时，`IsEnabled == false` 的用户登录会看到：

> **登录失败** — 账户已被禁用

同时会写入登录日志，Extra 为 `账户未开通`。

## 自定义提示文案

### 1. 实现解析器

在宿主项目（如 `NeoAdmin/Services/`）实现框架接口：

```csharp
using NeoAdmin.Blazor.Core.Identity;
using NeoAdmin.Blazor.Entities;

namespace NeoAdmin.Services;

/// <summary>
/// 未开通账号登录时的自定义提示。
/// </summary>
public sealed class PendingApprovalLoginMessageResolver : IDisabledAccountLoginMessageResolver
{
    public Task<string?> TryResolveAsync(SysUser user, CancellationToken cancellationToken = default)
    {
        // 返回 null 或空字符串时，框架回退为「账户已被禁用」
        return Task.FromResult<string?>("您的账号正在审核中，请耐心等待管理员开通。");
    }
}
```

接口定义（框架侧）：

```csharp
public interface IDisabledAccountLoginMessageResolver
{
    Task<string?> TryResolveAsync(SysUser user, CancellationToken cancellationToken = default);
}
```

可按 `user.Description`、角色、扩展字段等返回不同文案，例如：

```csharp
public Task<string?> TryResolveAsync(SysUser user, CancellationToken cancellationToken = default)
{
    if (user.Description.Contains("rejected", StringComparison.OrdinalIgnoreCase))
        return Task.FromResult<string?>("您的注册申请未通过，请联系管理员。");

    return Task.FromResult<string?>("您的账号正在审核中，请耐心等待。");
}
```

### 2. 注册到 DI

在 `Program.cs` 的 `AddNeoAdmin` 之前或之后添加：

```csharp
builder.Services.AddScoped<IDisabledAccountLoginMessageResolver, PendingApprovalLoginMessageResolver>();
```

`NeoAdminAuthService` 通过构造函数可选注入该接口，无需修改框架代码。

## 完整示例：注册后待审核

### 步骤 1：注册时设为未开通

修改宿主 `Api/LoginController.cs` 的 `Register` 方法，新用户默认 `IsEnabled = false`：

```csharp
var user = new SysUser
{
    Username = username,
    Nickname = string.IsNullOrWhiteSpace(request.Nickname) ? username : request.Nickname.Trim(),
    Password = request.Password,
    Description = request.Description?.Trim() ?? string.Empty,
    IsEnabled = false,   // 待管理员审核
    LoginTime = DateTime.Now
};
```

注册接口仍可返回「注册成功」，但用户此时无法登录。

### 步骤 2：配置自定义提示

按上一节实现并注册 `PendingApprovalLoginMessageResolver`。

### 步骤 3：管理员审核开通

管理员在 **系统管理 → 用户管理**（`/admin/user`）勾选用户的 **启用**，将 `IsEnabled` 设为 `true` 后，用户即可正常登录。

## API 与 Blazor 登录页

两种方式共用同一套 `NeoAdminAuthService.LoginAsync` 逻辑：

| 入口 | 说明 |
|------|------|
| `DefaultLogin.razor` | Blazor 登录页，`/login` |
| `POST /api/login/@Login` | REST API 登录 |

自定义提示对两者均生效。

## 注意事项

### CheckAsync 不使用自定义解析器

用户**曾经登录成功**、之后被管理员禁用的情况，`CheckAsync`（会话校验）对 `IsEnabled == false` 统一返回：

> 未登录或登录已过期

不会调用 `IDisabledAccountLoginMessageResolver`。自定义文案**仅在用户主动提交登录**（`LoginAsync`）时生效。

### 与审批流（EntityAudited）无关

`EntityAudited`、`CrudAuditPanel` 等是**业务数据**的审批流，与用户账号开通是两套机制。账号能否登录只看 `SysUser.IsEnabled`。

### 登录页 URL 参数

| 参数 | 说明 |
|------|------|
| `?redirect=/path` | 登录成功后跳转地址 |
| `?reason=kicked` | 账号在其他地方登录，显示「账号已在其他地方登录，请重新登录」 |

未开通账号提示不通过 URL 参数配置，由上述解析器或默认文案决定。
